# Housing Configurator — V4 (frozen snapshot)

Frozen **V4** — the **snap-together tile** approach (Phase B). Each module is its own
complete two-cover housing at its own height, and adjacent tiles connect with a **vertical
dovetail slide-joint** (tongue on the east, groove on the west, on N/S rail blocks that
widen the tile clear of the cable notch + cover latch).

- `main.js` builds a `LAYOUT` = a sequence of module tiles (`buildLayout`), each generated by
  `buildHousing(profile, 1, …, joints)` and spread across the bed.
- Modules: buzzer / knob / LED button / USB LEDs (40×40).

**Superseded** — Christopher moved away from the tile concept (V5 onward) to a single
**monolithic uniform box**: modules placed freely on a 2D grid (bird's-eye), a front + back
cover, and per-module M2.5-hole holding columns whose lengths adjust so every payload reaches
the front cover while the outer box stays one uniform height (no staircase). See the parent
folder for the live V5 rebuild.

- **Run it:** open `index.html` (self-contained `app.js`). Also `git tag housing-configurator-v4`.
