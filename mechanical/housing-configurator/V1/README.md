# Housing Configurator — V1 (frozen snapshot)

Frozen **V1** of the noknok housing configurator: the two-cover buzzer template,
print-validated on the Bambu X1C in PLA. Uses an **interference-fit** cover snap +
retention nibs with dialed-in clearances.

- **Run it:** open `index.html` — self-contained (`app.js` is the prebuilt bundle,
  three.js + JSCAD inside; no build or internet needed).
- `main.js` is the V1 source.

The **live** configurator (V2 onward — flexing cantilever latch, ramped retention,
`fit` parameter) is in the **parent folder**. V1 is also the git tag
`housing-configurator-v1`.
